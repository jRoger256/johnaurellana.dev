Full-stack software engineer (Laravel, Vue, Inertia.js). Nine years of experience shipping production web applications, now working with Claude Code.

## About

A static portfolio site with no build step: plain HTML, CSS and a small amount of JavaScript. It supports light and dark mode, is responsive, and prints cleanly as a one-document résumé.

## Structure

```
index.html          page content
assets/styles.css   design tokens and styles
assets/main.js      scroll reveal, nav highlight, copy-email
assets/favicon.svg  site icon
```

## Run locally

Open `index.html` in a browser, or serve the folder with any static server.
