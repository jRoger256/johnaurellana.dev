Workfolio · Process automation · No code

Client support ticketing

A workflow that gives clients one place to report a problem and gets each report to the right people. I configured it with ClickUp Forms and ClickUp Automations, then integrated it with Slack.

  1. Client submits a formThe ClickUp Form on our main website. The client picks the affected project.
  2. Ticket is createdThe request gets a ticket ID, and the client receives an automatic confirmation email.
  3. Task is filed by projectA task is created on the ClickUp board, in the folder for that project inside the ClickUp space.
  4. Team is tagged in SlackClickUp posts the ticket to the project's Slack channel and tags the people assigned to it.
  5. Client is told it's resolvedWhen the task status changes to complete, an automatic email tells the client the ticket is resolved.

AI workflow

How I work with AI.

I use Claude Code as an assistant on real production work. I am still growing my skill with it, and these are the habits that keep its output reliable.

  1. Give it the project's context

    Laravel Boost is installed and configured for Claude Code, so it sees my actual framework version, routes, database schema and docs instead of guessing.

  2. Work from a spec

    The Microsites build followed a written module spec and roadmap, so each change had a clear definition of done.

  3. Let tests catch mistakes

    The project has over 1,700 automated tests, and an automatic check that stops new screens from shipping without access rules.

  4. Review before it ships

    I read the diff, run the suite, and ship it through the same GitHub, Envoyer and Forge pipeline as any other code.
